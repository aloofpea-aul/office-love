# Office Love — ระบบเดินตรวจความปลอดภัยสำนักงาน กฟส.อ่าวลึก

เฟส 1–4 ตามแบบออกแบบ: ล็อกอินร่วมแพลตฟอร์ม · ลงเวลาเข้า-ออกเวร · เช็คอินตามจุดด้วย GPS ·
เช็คลิสต์ต่อจุด · ถ่ายรูปพร้อมบังคับทิศ · แจ้งเหตุผิดปกติ · คิวออฟไลน์ · สร้างรอบอัตโนมัติ ·

## ขั้นตอนติดตั้ง

### 1. สร้างชีตฐานข้อมูล

สร้าง Google Sheet ใหม่ ตั้งชื่อ **OfficeLove_DB** แล้วคัดลอก ID จาก URL

```
https://docs.google.com/spreadsheets/d/  ←ตรงนี้คือ ID→  /edit
```

ไม่ต้องสร้างแท็บเอง สคริปต์จะสร้างให้ทั้ง 16 แท็บ

### 2. สร้างโปรเจกต์ Apps Script

ไปที่ https://script.google.com → New project → ตั้งชื่อ **OfficeLove_API**
ลบโค้ดเดิมทิ้ง วางเนื้อหา `Code.gs` ลงไปทั้งไฟล์

แก้ 2 บรรทัดบนสุดของ `CFG`

```js
DB_SHEET_ID       : 'ID ของ OfficeLove_DB',
PLATFORM_SHEET_ID : 'ID ของชีตแพลตฟอร์มที่มีแท็บ Admins / Members',
```

ตั้งเขตเวลาของโปรเจกต์ให้ถูกด้วย — Project Settings → Time zone → **(GMT+07:00) Bangkok**
ถ้าตั้งผิด เวลารอบจะเพี้ยนทั้งระบบ

### 3. รัน setupAll() หนึ่งครั้ง

เลือกฟังก์ชัน `setupAll` แล้วกด Run — ครั้งแรกจะขออนุญาตเข้าถึง Sheets/Drive ให้กดอนุญาต

สิ่งที่เกิดขึ้น: สร้างแท็บทั้งหมด · ใส่ค่าระบบตั้งต้น · ใส่ตารางรอบ (วันทำการ 6 รอบ / วันหยุด 10 รอบ) ·
ใส่จุดตรวจ 6 จุด **พร้อมพิกัดชั่วคราว** · ใส่เช็คลิสต์ 3 ข้อ · ตั้ง trigger 3 ตัว · สร้างรอบของวันนี้กับพรุ่งนี้

รันซ้ำได้ทุกเมื่อ — ของเดิมไม่ถูกทับ และจะเติมค่าระบบใหม่ที่เพิ่มมาภายหลังให้ด้วย

### 4. Deploy เป็น Web App

Deploy → New deployment → เลือกชนิด **Web app**

| ช่อง | ค่า |
| --- | --- |
| Execute as | Me |
| Who has access | **Anyone** |

คัดลอก **Web app URL** ที่ได้

> ทุกครั้งที่แก้ `Code.gs` ต้อง Deploy → Manage deployments → แก้ไข → Version: New version
> ไม่งั้น URL เดิมจะยังรันโค้ดเก่า

### 5. ตั้งค่าไฟล์หน้าเว็บ

แก้ไฟล์เดียว — `config.js` (ทั้งสามหน้าอ่านค่าจากไฟล์นี้)

```js
window.OL_API = 'วาง URL ของ Web App ตรงนี้';
```

### 6. อัปขึ้น GitHub Pages

สร้าง repo ชื่อ `office-love` ในบัญชี `aloofpea-aul` → อัปโหลดไฟล์หน้าเว็บทั้งหมด →
Settings → Pages → Source: `main` / `root`

ได้ URL: `https://aloofpea-aul.github.io/office-love/`

### 7. เปิดสิทธิ์ให้ รปภ.

ในชีตแพลตฟอร์ม แท็บ `Members` ใส่ `OFFICELOVE` ในคอลัมน์ `Apps` ของแต่ละคน
(ถ้าในคอลัมน์มีแอปอื่นอยู่แล้ว ให้ต่อท้ายด้วยเครื่องหมายจุลภาค)

ระบบตรวจสิทธิ์แบบนี้

| แท็บที่พบ | สิทธิ์ที่ได้ |
| --- | --- |
| `Admins` | `ADMIN` |
| `Members` + คอลัมน์ Role/Level มีคำว่า ADMIN | `ADMIN` |
| `Members` + Role/Level มีคำว่า SUPER หรือ หัวหน้า | `SUPERVISOR` |
| `Members` อื่น ๆ | `GUARD` |

ชื่อผู้ใช้อ่านจากคอลัมน์ชื่อใดก็ได้ในกลุ่มนี้: `Username`, `User`, `UserId`, `Phone`, `เบอร์โทร`, `Email`
รหัสผ่านอ่านจาก `Password`, `Pass`, `รหัสผ่าน` — เก็บเป็นข้อความตรง หรือ SHA-256 ก็ได้ ระบบตรวจให้เอง

## งานที่ต้องทำก่อนใช้จริง

### เก็บพิกัดจุดตรวจ (สำคัญที่สุด)

**พิกัดตั้งต้นของทั้ง 6 จุดเป็นค่าเดียวกันหมด** เพราะข้อมูลในชีต AppSheet เก่าไม่ใช่ lat/lng จริง
ต้องเดินเก็บใหม่ทุกจุด มิฉะนั้นระบบจะเช็คอินจุดไหนก็ผ่านหมด

1. เปิด `admin.html` บนมือถือ ล็อกอินด้วยบัญชีแอดมิน
2. ไปยืนที่จุดจริง แตะจุดนั้นในตาราง → กด **📍 ใช้ตำแหน่งปัจจุบัน**
3. รอให้เก็บครบ 30 ค่า (ราว 30 วินาที) ระบบจะเฉลี่ยเฉพาะค่าที่แม่นที่สุด 60% ให้
4. กดบันทึก แล้วเดินไปจุดถัดไป

ถ้ามีแบนเนอร์แดงเตือนว่าสองจุดห่างกันไม่ถึง 15 เมตร แปลว่า GPS แยกสองจุดนั้นไม่ออก —
ต้องลดรัศมี หรือรอเฟส 5 ที่เพิ่ม QR ที่จุด

### ตั้งทิศถ่ายรูป

ที่จุดที่ต้องการบังคับทิศ ให้ยืนที่จุด หันกล้องไปทางที่ต้องการ แล้ว

1. กด **อ่านทิศตอนนี้** — ช่ององศาจะเติมให้เอง (iOS จะมี popup ขออนุญาตครั้งแรก)
2. เลือกรูปตัวอย่างจากกล้อง — รูปนี้จะไปซ้อนจาง ๆ บนกล้องของ รปภ.
3. ตั้งค่าเบี่ยงเบนที่ยอมรับ ค่าแนะนำ ±45°

> **อย่าตั้งทิศที่จุดซึ่งมุมกล้องชี้เข้าหาหม้อแปลงหรือตู้สวิตช์โดยตรง**
> สนามแม่เหล็กจากอุปกรณ์ทำให้เข็มทิศมือถือเพี้ยนได้เกิน 90°
> จุดแบบนั้นให้เว้นช่ององศาไว้ว่าง แล้วใช้รูปตัวอย่างซ้อนเป็นตัวบังคับแทน — เชื่อถือได้มากกว่า
>
> ทิศที่ไม่ตรงจะ **ไม่บล็อก** การถ่าย แต่บันทึก `headingOk = FALSE` ไว้ในแท็บ `Attachments`

### เปิดแจ้งเตือนก่อนถึงรอบ

ระบบเตือนสองชั้น ทำงานคู่กัน

| ชั้น | เตือนตอนไหน | ต้องเปิดแอปค้างไว้ไหม |
| --- | --- | --- |
| **Webex** (แนะนำ) | ก่อนถึงรอบ 10 นาที · และเตือนซ้ำเมื่อเลยเวลารอบ 20 นาทีแล้วยังไม่มีใครเช็คอิน | ไม่ต้อง — เด้งที่แอป Webex บนมือถือ |
| **ในแอป** | แถบนับถอยหลังรอบถัดไป + เด้งแจ้งเตือนบนเครื่อง | ต้องเปิดแอปค้างไว้ |

#### ตั้ง Webex (ฟรี ไม่มีโควตารายเดือน)

1. ไปที่ https://developer.webex.com → My Webex Apps → **Create a Bot**
   ตั้งชื่อบอต เช่น `Office Love` แล้วกดสร้าง — **คัดลอก access token เก็บไว้ทันที เพราะแสดงครั้งเดียว**
2. ใน Webex สร้างสเปซสำหรับ รปภ. แล้ว **เชิญบอตเข้าสเปซ** ด้วยอีเมลบอต (ลงท้าย `@webex.bot`)
3. ใน Apps Script → แก้ฟังก์ชัน `setWebexToken()` ใส่โทเคน → Run หนึ่งครั้ง → ลบโทเคนออกจากโค้ด
4. รันฟังก์ชัน `listWebexRooms()` หนึ่งครั้ง → ดู Execution log จะได้ชื่อสเปซคู่กับ `roomId`
5. ในหน้าแอดมิน แท็บ **ค่าระบบ** ใส่
   - `NOTIFY_CHANNEL` = `WEBEX`
   - `WEBEX_GUARD_ROOM` = roomId ของสเปซ รปภ.
   - `WEBEX_SUPERVISOR_ROOM` = roomId ของสเปซหัวหน้าเวร (เว้นว่าง = ใช้สเปซเดียวกัน)
   - ถ้าอยากส่งหารายคนแทนสเปซ ใส่อีเมลคั่นจุลภาคใน `WEBEX_GUARD_EMAILS`
6. กด **ส่งข้อความทดสอบ** ในการ์ด *ทดสอบแจ้งเตือน* ใต้ตารางค่าระบบ

ปรับจังหวะเตือนได้ที่ `REMIND_BEFORE_MIN` (ตั้งต้น 10 นาที) และ `REMIND_LATE_MIN` (ตั้งต้น 20 นาที)
ทุกข้อความที่ส่งบันทึกไว้ในแท็บ `Notifications` — ระบบใช้ตารางนี้กันส่งซ้ำรอบเดิมด้วย

#### ถ้าจะใช้ LINE แทน

ตั้ง `NOTIFY_CHANNEL` = `LINE` (หรือ `BOTH` ถ้าอยากได้ทั้งสองทาง) แล้ว

1. ใน Apps Script → แก้ฟังก์ชัน `setLineToken()` ใส่ channel access token → Run หนึ่งครั้ง → ลบโทเคนออกจากโค้ด
2. ใส่ `LINE_GUARD_TARGET` / `LINE_GUARD_MEMBERS` (กลุ่ม รปภ.) และ
   `LINE_SUPERVISOR_TARGET` / `LINE_SUPERVISOR_MEMBERS` (หัวหน้าเวร)

> LINE ฟรี 300 ข้อความ/เดือน และ **นับตามจำนวนคนในกลุ่ม** — เตือนทุกรอบ (216 รอบ/เดือน) จะเกินโควตาแน่นอน
> ตัวกันโควตาจึงทำงานอัตโนมัติ: เกิน 250 ข้อความ/เดือน ส่งเฉพาะเรื่องด่วน เกิน 290 หยุดส่งทั้งหมด
> รายการที่ถูกข้ามบันทึกไว้ในแท็บ `Notifications` สถานะ `SKIPPED_QUOTA`
> นี่คือเหตุผลที่แนะนำ Webex เป็นช่องทางหลัก

ปิดการแจ้งเตือนทั้งหมดได้ด้วย `NOTIFY_CHANNEL` = `OFF`

## การใช้งานประจำวันของ รปภ.

1. เปิด `https://aloofpea-aul.github.io/office-love/` แล้วกด **เพิ่มไปยังหน้าจอโฮม** (ทำครั้งเดียว)
2. ล็อกอิน — ระบบจำไว้ 30 วัน
3. กด **ลงเวลาเข้าเวร**
4. ครั้งแรกให้กด **🔔 เปิดแจ้งเตือนบนเครื่องนี้** ที่แถบนับถอยหลังรอบถัดไป (กดครั้งเดียวจำไว้ตลอด)
5. แตะรอบที่ถึงเวลา → แตะจุด → รอ GPS → ตอบเช็คลิสต์ → ถ่ายรูป → **บันทึกเช็คอิน**
6. พบเรื่องผิดปกติ กด **⚠️ แจ้งเหตุ** ได้ทุกหน้า
7. จบเวรกด **ออกเวร**

ถ้าสัญญาณขาด แถบเหลืองด้านบนจะบอกว่ามีกี่รายการรอส่ง — แตะแถบเพื่อส่งทันทีเมื่อเน็ตกลับมา

| ตารางรอบ × จุดตรวจ | ตารางเดียวเห็นทั้งคืน แต่ละช่องคือเวลาที่เช็คอิน แตะเพื่อดูรูปและระยะ GPS |

## รายงานรายเดือน (`report.html`)

หน้านี้ทำมาเพื่อใช้เป็นเอกสารประกอบการ **ตรวจรับงานจ้าง รปภ.** โดยเฉพาะ
เข้าได้ด้วยบัญชี `SUPERVISOR` หรือ `ADMIN` เปิดจากปุ่ม 📄 ในหน้าหัวหน้าเวร

| ส่วน | สิ่งที่ได้ |
| --- | --- |
| สรุปภาพรวม | รอบทั้งเดือน · % ครบรอบ · % ตรงเวลา · % ครบจุด · รอบขาด/ไม่ครบ · เหตุการณ์ · จำนวนรูปหลักฐาน |
| ผลรายวัน | แยกวันทำการ/วันหยุด พร้อมจำนวนรอบและจุดที่เดินจริง |
| ผลแยกตามรอบ | รอบไหนของคืนที่มักขาด |
| ผลแยกตามพนักงาน | จำนวนเวร ชั่วโมงทำงาน เช็คอิน รายการที่ติดธง และที่ยืนยันเอง |
| เหตุการณ์ | ทุกเรื่องที่แจ้งในเดือนนั้น พร้อมผู้รับผิดชอบและสรุปการแก้ไข |
| ลายเซ็น | ช่องผู้จัดทำรายงาน และผู้ตรวจรับงานจ้าง |

- ปุ่ม **🖨 พิมพ์ / บันทึก PDF** จัดหน้าเป็น A4 ให้อัตโนมัติ (ตัดเมนูและปุ่มออกหมด)
- ปุ่ม **⬇ CSV** ดาวน์โหลดข้อมูลดิบของเดือนนั้น เลือกได้ 4 ตาราง: `Rounds` / `Checkins` / `Incidents` / `Shifts`
  ไฟล์มี BOM เปิดใน Excel ภาษาไทยไม่เพี้ยน

### ปิดงวดเดือน

เมื่อตรวจรับงานเดือนนั้นเรียบร้อยแล้ว ผู้ดูแลระบบกด **ปิดงวดเดือนนี้** ได้จากหน้ารายงาน
หลังปิดแล้ว ระบบจะปฏิเสธการเช็คอิน การแจ้งเหตุ และการแก้ไขเหตุการณ์ที่ตกอยู่ในเดือนนั้นทั้งหมด
เพื่อให้ตัวเลขในรายงานที่ใช้ประกอบการเบิกจ่ายไม่เปลี่ยนย้อนหลัง

การปิด/เปิดงวดทุกครั้งบันทึกไว้ในแท็บ `AuditLog` (`MONTH_LOCK` / `MONTH_UNLOCK`)
ถ้าจำเป็นต้องแก้จริง ๆ ผู้ดูแลกด **เปิดงวดอีกครั้ง** ได้ แต่จะมีร่องรอยไว้เสมอ

## แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุและวิธีแก้ |
| --- | --- |
| กดล็อกอินแล้วไม่มีอะไรเกิดขึ้น | `API` ยังเป็นข้อความตัวอย่าง หรือ deployment ตั้ง Who has access ไม่ใช่ Anyone |
| "บัญชีนี้ยังไม่ได้รับสิทธิ์ใช้ Office Love" | ยังไม่ได้ใส่ `OFFICELOVE` ในคอลัมน์ `Apps` |
| เช็คอินขึ้น "อยู่นอกรัศมี" ทั้งที่ยืนตรงจุด | พิกัดจุดยังเป็นค่าตั้งต้น ให้ไปเก็บพิกัดจริงในหน้าแอดมิน |
| กล้องในหน้าเว็บไม่ขึ้น | บางเครื่องบล็อก `getUserMedia` — ใช้ปุ่ม "กล้องของเครื่อง" ด้านล่างแทน ได้ผลเหมือนกัน |
| เข็มทิศไม่ขยับบน iPhone | ต้องกดปุ่มก่อนหนึ่งครั้งเพื่อให้ขออนุญาต และหน้าเว็บต้องเป็น HTTPS |
| แก้ไฟล์บน GitHub แล้วมือถือยังเห็นของเก่า | แก้เลข `VERSION` ใน `sw.js` แล้วอัปใหม่ |
| รอบวันนี้ไม่ขึ้น | รัน `dailyGenerateRounds()` จาก Editor หนึ่งครั้ง แล้วตรวจว่า trigger ถูกสร้างใน Triggers |
| รอบทั้งวันขึ้นเป็นเวลา 07:00 และ MISSED หมด | Google Sheets แปลง `18:00` ในแท็บ `RoundPlan` เป็นค่าเวลาแทนข้อความ — รัน `fixAndRebuild()` หนึ่งครั้ง จะจัดรูปแบบคอลัมน์เป็นข้อความและสร้างรอบใหม่ให้ |
| บันทึกเช็คอินแล้วขึ้น "ปิดงวดแล้ว" | เดือนนั้นถูกปิดงวดไว้ — ผู้ดูแลเปิดงวดอีกครั้งได้ที่หน้ารายงาน |
| กดทดสอบแจ้งเตือนแล้วไม่เข้า Webex | บอตยังไม่ได้ถูกเชิญเข้าสเปซ หรือ `WEBEX_GUARD_ROOM` ผิด — รัน `listWebexRooms()` ดู roomId ที่ถูกต้อง |
| ไม่มีค่าระบบ `WEBEX_*` ในตาราง | รัน `upgradeConfig()` หรือ `setupAll()` ใน Apps Script หนึ่งครั้ง ระบบจะเติมค่าที่ขาดให้โดยไม่ทับของเดิม |
| มือถือไม่เด้งแจ้งเตือนในแอป | ยังไม่ได้กดปุ่ม 🔔 หรือปิดสิทธิ์ไว้ — iOS ต้องกด **เพิ่มไปยังหน้าจอโฮม** ก่อนจึงจะแจ้งเตือนได้ |
