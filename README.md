# Office Love

ระบบเดินตรวจความปลอดภัยสำนักงาน กฟส.อ่าวลึก — สำหรับพนักงานรักษาความปลอดภัย (รปภ.)

หน้าเว็บเป็น PWA บน GitHub Pages หลังบ้านเป็น Google Apps Script + Google Sheets

## ไฟล์

| ไฟล์ | ใครใช้ |
| --- | --- |
| `index.html` | รปภ. — เข้า-ออกเวร เช็คอินตามจุด เช็คลิสต์ ถ่ายรูป แจ้งเหตุ |
| `supervisor.html` | หัวหน้าเวร — ตารางรอบ × จุด แผนที่ เหตุการณ์ กราฟ 30 วัน |
| `admin.html` | ผู้ดูแล — ตั้งจุดตรวจ ทิศถ่ายรูป เช็คลิสต์ ตารางรอบ วันหยุด |
| `config.js` | URL ของ Apps Script Web App — แก้ที่เดียวเวลา deploy ใหม่ |
| `sw.js` | service worker — แก้เลข VERSION ทุกครั้งที่อัปไฟล์ใหม่ |
| `manifest.json` | ข้อมูลแอปตอนเพิ่มไปหน้าจอโฮม |
| `Code.gs` | โค้ดหลังบ้าน — สำเนาไว้ใน repo ตัวจริงรันที่ Apps Script |

## เอกสารออกแบบ

ดูแบบออกแบบฉบับเต็มในเอกสารของโครงการ ครอบคลุมโครงสร้างข้อมูล รอบเดินตรวจ การยืนยันด้วย GPS และแผนพัฒนาเป็นเฟส
